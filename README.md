# Kreyli Coop AOH2

Лаунчер и обновления неофициального кооперативного дополнения для Age of History 2: Definitive Edition 2.01.

## Возможности

- Два игрока: общая страна или отдельные страны.
- Лобби с готовностью обоих перед выбором новой игры или сохранения.
- Комнаты Kreyli, единый ник из лаунчера и Discord.
- LAN/RadminVPN/Hamachi и интернет-комнаты по коду.
- Steam AppID 480 (Spacewar), оверлей и приглашения в уже запущенную игру.
- Проверка обновлений лаунчера и мода при каждом открытии и перед игрой; SHA-256, откат при ошибке, сохранение ника и сохранений.

## Канал обновлений

Releases содержат обновления для установленной сборки Kreyli. Коммерческая игра, её ресурсы и полный игровой установщик здесь не публикуются.

Рядом с лаунчером нужен файл `update-channel.json`:

```json
{"manifestUrl":"https://github.com/Kreyli/Kreyli-Coop-AOH2/releases/latest/download/update.json"}
```

Новые версии приходят после публикации в Releases. Изменение исходников само по себе не публикует обновление.

## Сеть и ограничения

Перед Steam-приглашением оба игрока должны запустить Kreyli Coop AOH2. Steam должен быть запущен, оверлей включён. Интернет-комнаты используют relay исходного мода; его доступность зависит от автора. Для LAN Steam не требуется.

Сборка экспериментальная. Проверены два локальных игровых процесса, готовность лобби, экономика, набор армии, следующий ход, лимит участников, настоящее Steam-лобби и открытие окна приглашений. Приём приглашения вторым Steam-аккаунтом и длительные кампании полностью не проверены.
