# Обновления Kreyli Coop AOH2

Канал подключён 28 октября 2026. Первый опубликованный выпуск — v1.0.0:
https://github.com/Kreyli/Kreyli-Coop-AOH2/releases/tag/v1.0.0

Лаунчер проверяет https://github.com/Kreyli/Kreyli-Coop-AOH2/releases/latest/download/update.json при открытии и перед запуском игры. Начиная с 1.0.2 автообновление всегда включено, переключатель удалён. Прежний manual-updates.flag игнорируется. Загрузка поддерживает паузу. Размер и SHA-256 проверяются перед применением. Помощник ждёт закрытия старого EXE, заменяет файлы и запускает новый лаунчер. При ошибке замены выполняется откат. Ник, сохранения и настройки не входят в обновление.

Проверено: код лаунчера скачал реальный опубликованный манифест и все 10 файлов, подтвердил размеры и SHA-256, затем перестал предлагать обновление при версии 1.0.0. Отдельно пройдены 26 проверок безопасности путей, целостности, отката и сохранения данных, а также проверка замены работающего EXE и запуска новой версии.

## Следующий выпуск

1. Внести изменения, собрать и проверить игру и лаунчер. Увеличить версию (например, 1.0.1) в сборке лаунчера, установщике и описании выпуска.
2. Выполнить make-release.ps1 -Version 1.0.1 -AssetBaseUrl https://github.com/Kreyli/Kreyli-Coop-AOH2/releases/download/v1.0.1 -Payload <папка сборки>.
3. Создать новый релиз с тегом v1.0.1 и загрузить все 11 подготовленных файлов, включая update.json. Не заменять содержимое уже выпущенной версии.
4. После проверки опубликовать обычный релиз как Latest. Закрытый черновик и Pre-release не используются каналом latest.
5. Повторить проверку живого канала и контрольных сумм.

После публикации пользователи с новым установщиком получат обновление при следующем открытии лаунчера. Редактирование исходников само по себе не публикует выпуск. Закрытый лаунчер ничего не скачивает. Токен GitHub пользователям не нужен.

Полную игру и полный локальный установщик в публичный GitHub не загружать. Установка после удаления использует предоставленный владельцем архив Google Drive с фиксированной контрольной суммой, плюс совместимую сетевую основу, Java и распаковщик из локального установщика. При недоступности или изменении исходного архива установка прекращается с сообщением об ошибке. Уже скачанная часть сохраняется; повторная загрузка использует Range и проверяет итоговый SHA-256.

Неопубликованный прежний черновик сохранён отдельно под тегом draft-before-launcher и не участвует в обновлениях.
