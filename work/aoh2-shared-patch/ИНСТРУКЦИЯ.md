# Совместная игра в Age of History 2: Definitive Edition

Тестовая сборка: мод автора AoH2DE Multiplayer 2.2 и отдельный патч общей страны. Нужны ресурсы DE 2.01 и Java 21. У всех участников должны быть одинаковые мод и патч. Обычный AoH2 Multiplayer и неизменённый AoH2DE Multiplayer к этой сборке не подключатся.

## Запуск на этом компьютере

Откройте `Play-Coop.cmd` в отдельно созданной папке `work/aoh2-play`. Оригинальная установка и её сохранения не изменялись. Новые кампании этой сборки сохраняются отдельно.

1. В главном меню откройте Multiplayer и задайте свой ник.
2. Хост выбирает создание игры. В строке **Страны** переключаются **общая страна** и **отдельные страны**.
3. Для игры через сервер автора выберите **Соединение: код комнаты**, затем доступный регион, например EU Central. Задайте пароль. Публичный список можно оставить выключенным.
4. Создайте комнату, выберите сценарий и страну хоста, начните кампанию. Передайте друзьям код комнаты и пароль самостоятельно.
5. Гости открывают подключение, вводят код и пароль. После загрузки выбирают страну на карте. В общем режиме выбирается страна хоста; в раздельном — свободная страна.
6. Оба игрока могут отдавать приказы в одном ходе. Для перехода хода каждый нажимает завершение хода. В общей стране дождитесь подтверждения последнего приказа.

Для локальной сети выберите **по IP**; гость вводит адрес хоста и порт, например `192.168.1.10:27026`. `127.0.0.1` используется только для двух копий на одном компьютере. Изменения маршрутизатора и брандмауэра установщик не делает.

## Установка у друзей

Архив патча не содержит игру или мод автора. Каждый участник использует свою установку DE 2.01, Java 21 и скачивает **Definitive Edition → Desktop** с сайта автора: https://aoh2mp.web.app/ (новый адрес: https://ageofhistory.mp/).

Эта версия патча принимает только архив AoH2DE-MP.jar с SHA-256:

`DB144F0DDB7E62DE92AD971EB7BC0B9A66B57CABBFE70B9DCDA7D2A70204704C`

Если автор обновил файл, установщик остановится: другая версия требует отдельной проверки.

Распакуйте патч, откройте PowerShell в его папке и укажите свои пути:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 `
  -GameDirectory "D:\Games\Age of History 2 Definitive Edition" `
  -UpstreamJar "D:\Downloads\AoH2DE-MP.jar" `
  -Destination "D:\Games\AoH2-Coop"
```

Папка назначения должна быть новой и находиться вне исходной установки. Установщик копирует ресурсы, создаёт отдельные сохранения и добавляет `Play-Coop.cmd`. Java не скачивается и не устанавливается автоматически. Штатная Java 8 из игры для патча не подходит.

## Что проверено и что остаётся

Автоматические тесты с двумя настоящими игровыми процессами проверили оба режима стран, выбор режима в форме создания, инвестиции, набор солдат, объявление войны, приказ атаки и переход хода. Для военного сценария сравнивались армии, очереди, очки действий, золото, союзы и владельцы провинций. Проверены конкурирующие расходы общей казны и сохранение управления хостом после выхода гостя.

Это ограниченная проверка, а не гарантия всех игровых механик. Долгие кампании, три и более участника, все события, морские операции и восстановление после сетевых сбоев ещё не прошли полный набор тестов. Общая страна передаёт снимки состояния после приказов: возможны заметные паузы. Для начала создайте новую пробную кампанию.

Результат отдельной проверки сервера-посредника и окончательной упаковки записывается в `TEST-RESULTS.md`. При проблемах смотрите `coop.out.log` и `coop.err.log` в папке отдельной установки.
