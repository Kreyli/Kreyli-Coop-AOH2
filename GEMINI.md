# Kreyli Coop AOH2 — постоянные правила

Проект: Kreyli Coop AOH2.
GitHub: https://github.com/Kreyli/Kreyli-Coop-AOH2

Перед работой:
- Выполняй git status -uno.
- Не сканируй всю папку work рекурсивно.
- Работай прежде всего с work\aoh2-shared-patch, work\kreyli-installer, work\kreyli-steam и work\kreyli-filter.
- Не удаляй файлы пользователя и не используй git reset --hard.

После каждой задачи, которая изменила исходники мода, Steam-интеграции, лаунчера или установщика:
1. Собери затронутые компоненты.
2. Запусти подходящие тесты.
3. Если тесты прошли, автоматически подготовь и опубликуй обновление.
4. Перед релизом определи текущую последнюю версию и увеличь её на один патч.
5. Обнови версию во всех местах:
   - update.json;
   - Launcher.cs и AssemblyVersion;
   - setup.iss;
   - пользовательскую надпись версии в игре;
   - другие видимые пользователю тексты версии.
6. Проверь через rg, что старая версия не осталась в пользовательском интерфейсе.
7. Сделай git commit и git push в main.
8. Создай GitHub Release с тегом vX.Y.Z, пометь его Latest.
9. Загрузи все файлы, указанные в update.json, включая update.json.
10. Проверь latest/download/update.json и доступность файлов обновления.
11. В конце дай ссылку на Release.

Не публикуй релиз, если задача была только вопросом, анализом или проверкой без изменения исходников, а также если сборка или тесты не прошли.

Никогда не добавляй в Git или Release:
- work\coop-anything;
- оригинальную игру, RAR-архивы;
- payload-*, output, tools;
- временные тесты, build, smoke, inspection;
- .exe, .class и .jar, кроме специально подготовленных файлов, перечисленных в update.json.

Бренд: Kreyli Coop AOH2.
Не возвращай LeoC, ageofhistory.mp и старые серверы.
Steam используется как Spacewar. Для Steam-приглашений и LAN/RadminVPN/Hamachi сохраняй работоспособность.
